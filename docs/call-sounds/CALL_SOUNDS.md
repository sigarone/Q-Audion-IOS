# Q-Audion call sounds

All sounds are generated by `gen_call_sounds.py` from code (sine partials, FM synthesis and a seeded noise source). No recordings, samples, existing melodies or third-party audio are used. Running the script reproduces every file byte for byte.

Format: 48 kHz, mono, 16-bit PCM WAV. The tonal centre is D Dorian pentatonic, matching the in-app synthesizers. All pitched content sits at or above roughly 290 Hz and the cues sit mostly between 400 Hz and 2.5 kHz, so they stay audible on phone earpieces and speakers.

## Loop rule

Files marked "loop" are built circularly: notes that ring past the end of the unit wrap onto its beginning, so the last sample flows into the first with no fade and no click. Play them with seamless looping. A loop ends and restarts without any gap; the silence inside each unit is part of the cadence. The 28 s ringtone files are the loop unit repeated an exact whole number of times, with a 3 ms fade-in and a 50 ms fade-out at the file ends only (the iPhone system call screen requires a file of at most 30 s).

## Levels

Peak never exceeds -1 dBFS (a soft limiter above 60 percent of full scale handles transients). Loudness is measured with an ITU-R BS.1770 K-weighted, gated integrated measurement. Ringtones target -14 LUFS, cues -16 LUFS. Sounds with a low crest factor reach the target with peaks below -1 dBFS; the peak ceiling always wins. The dialing tick is normalised to -1 dBFS peak because it is too short for a loudness target.

Ringtones (incoming call), each as `ringtone_<id>_loop.wav` and `ringtone_<id>_28s.wav`:

| id | Name | Loop | Character |
|---|---|---|---|
| vetro | Vetro | 4.0 s | Glass bell, rising four-note figure then a softer echo phrase |
| impulso | Impulso | 3.5 s | Soft rounded pulses in two rising pairs |
| arpeggio | Arpeggio | 4.0 s | Minimal plucked arpeggio, up and down, then a short lift |
| calore | Calore | 5.6 s | Warm swelling chords with a quiet bell on top |

| legno | Legno | 4.0 s | Wooden marimba-like bars, two short phrases |
| duetto | Duetto | 4.0 s | Two-tone phone-like warble with an original timbre and pitches |

Cues:

| File | Purpose | Duration | Loop | Character |
|---|---|---|---|---|
| cue_connecting.wav | Outgoing call being set up | 2.0 s | yes | Four soft plucked pulses, 440-660 Hz, clearly different from ringback |
| cue_ringback.wav | Far end is ringing | 4.0 s | yes | 425 Hz, 1 s on, 3 s off, soft envelope (60 ms attack, 120 ms release) |

| cue_ended.wav | Call ended | 0.9 s | no | Short descending three-note chime |

| cue_dialing_tick.wav | Call start | 50 ms | no | Very short soft click, played once |

## Regenerating

`python gen_call_sounds.py` (Python 3.9+, numpy). It rewrites all WAV files and the `preview/` folder, and prints duration, peak, RMS, loudness and a loop-seam check for each file.
